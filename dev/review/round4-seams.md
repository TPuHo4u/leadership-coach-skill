## (2) and (3) Findings

**B1 — important — the label rule is still not consistent across the references.**
- **SKILL.md:65–66:** the label marks *only* written-only cues and a tool moved to a new situation, «never a course term or signal».
- **References that still use the label because of the medium (the reason the rule removes):**
  - feedback-control.md:225 «Signals in writing (вывод, не из курса): a short defiant «и что?»; a long reply about something else». But :198 and :200 in the same file list «И что?» (перехват власти) and the long off-topic answer («красивая история») as course signals.
  - motivation.md:32 «Signals in written messages — вывод, не из курса: … «деньги» …». But :30 lists «деньги» as a course signal.
  - hiring.md:5, the file's definition of the label: «including everything about reading written messages». This states the rule that was replaced.
  - team.md:18 «Written signals (вывод, не из курса)». The phrases are not course phrases, so the label holds, but the heading suggests that "written" is the reason.
- **A third class SKILL.md leaves out:** several references label a reading the course does not give, even when the phrase is spoken or written. Examples: situational.md:90, :93, :94; development.md:28, :42, :199; motivation.md:30 «Also (вывод)». situational.md:96 names this class itself (««вывод» rows add an interpretation»). SKILL.md uses it too, at :125, :140 and :156. But the «only» list at :65–66 excludes it.
- **Wrong answer 1:** «Сотрудник ответил в чате на моё замечание: «и что?»». A model following feedback-control.md:225 writes «перехват власти — вывод, не из курса». That labels a course term as not from the course, which is exactly the J-S10 failure the round-2 judge flagged, one file over.
- **Wrong answer 2:** «Сотрудник пишет: «Мне надо согласовывать каждый шаг»». A model reading SKILL.md alone presents «чрезмерное руководство» as the course's signal with no label, while situational.md:93 labels it.
- **Fix:**
  - Reword feedback-control.md:225 to keep only «no answer» as a transfer and treat «и что?» and the long reply as the course's signals.
  - Reword motivation.md:32 so the label attaches to the reading (vague words → ask what the person means), not to the medium.
  - Replace hiring.md:5 «everything about reading written messages» with the written-only cues.
  - In SKILL.md, add «or a reading the course does not give» to the label scope at :65–66. Only 3 words of headroom are left, so this has to replace other words.
- **Fidelity:** the core of the rule is faithful. situational.md:46–52 gives signals from speech and behaviour, and some are non-verbal (закрытая поза, негативная мимика, говорит с энтузиазмом). These belong in the transfer class when read from text. SKILL.md:65 does this by listing «tone», and situational.md:77 says the same.
